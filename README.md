# HomeworkHelper

HomeworkHelper는 Windows PC에서 게임과 프로그램의 이용 기록을 관리하고, macOS에서 원격으로
연결·실행·종료할 수 있는 개인용 보조 앱입니다.

## 주요 기능

- **게임·프로그램 관리**: 실행 대상과 바로가기를 등록하고 실행·종료와 이용 시간을 관리합니다.
- **게임 자원 확인**: 지원하는 게임의 자원과 회복 시간을 확인하고 종료 후 조회 결과를 기록합니다.
- **Windows 사이드바**: 게임 제어, 음량, 스크린샷과 갤러리, OBS 녹화 연동을 제공합니다.
- **macOS 원격 클라이언트**: 메뉴 막대에서 호스트 상태를 확인하고 Moonlight 연결과 게임 제어를 사용합니다.
- **로그인 전 원격 접근**: Tailscale과 Apollo를 통해 로그인 화면에 접근합니다. 전체 앱 기능은 지정
  사용자가 Windows에 로그인하고 호스트 앱이 준비된 뒤 사용할 수 있습니다.
- **이용 기록과 대시보드**: 호스트가 보관한 데이터로 이용 현황을 확인합니다.

Windows 앱은 PySide6 + Qt Widgets, macOS 클라이언트는 네이티브 Swift UI를 사용합니다.
게임 데이터는 Windows 호스트가 보관하며 원격 앱 기능은 페어링과 인증을 사용합니다.

설치·개발·문제 진단·빌드·배포·정책과 공용 도구는 [종합 작업 가이드](docs/WORK_GUIDE.md)에서 안내합니다.
